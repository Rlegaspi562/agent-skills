# Banned defaults

From Florence (@flxrnc). Without design direction the model falls back on a few default styles, and "avoid a generic AI look" mostly swaps one default for another. Name the exact patterns instead.

## Starting ban list

- purple or blue gradients, glow, lens flares
- floating particles as decoration
- everything fading in at once
- fade-and-slide-up on every element
- centered-everything layouts
- text that moves while it is being read

## Product-shot ban line used in Prompt B

```text
BANNED: purple or blue gradients, glow orbs, bloom, neon, lens flares, particles, generic spinning turntables, dark backgrounds, text.
```

The vague Prompt A came back with dark navy space, a glowing halo ring, bloom, particles, spinning buds and a made-up tagline: most of that list.

## Keep it alive

After every first render, name what the model used anyway and add it to the list.
