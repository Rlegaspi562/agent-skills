# Preset: White flash + shutter

**id:** `white-flash-shutter`

## When to use
Punctuate hook → story, or between list beats ("First" / "Second").

## Look / motion
- Full-frame white solid, opacity 0 → ~80–100 → 0 over ~3–6 frames.
- Optional slight scale punch on the A-roll under it.

## SFX
Camera **shutter** click aligned to peak white; optional soft whoosh.

## DaVinci Resolve Studio
1. Generator → Solid Color white on V3, 4–6 frames.
2. Opacity keyframes; ease in/out.
3. Fairlight: drop shutter one-shot; align to mid-flash.
4. Save Edit page compound clip or preset in Power Bin.
