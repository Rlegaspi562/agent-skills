# Preset: Tech diagram panel

**id:** `tech-diagram-panel`

## When to use
Top half of `split-screen-explainer` — architecture boxes, throughput charts, logo + badge callouts.

## Look
- Off-white / cream field.
- Black outlined rounded rects, thin connectors, all-caps labels.
- Accents: **red** for peak/fail, **green** for healthy metric bars.
- Product logos (VS Code, GitHub) as flat icons with light shadow OK.

## Motion
- Hard cut to next diagram state.
- Optional: line-graph reveal, progress bar fill, icon pop.

## DaVinci Resolve Studio
1. Build stills in Figma/Canva or Fusion nodes; export PNG sequence per beat.
2. Or Fusion: Text + Rectangle + Merge for live boxes.
3. Place only in top safe area; never cover face.
4. Keep one idea per state (peak graph OR sidecar diagram OR logo pair).
