# Preset: Black-box captions

**id:** `black-box-captions`

## When to use
Phrase-chunk captions that must read on busy kitchens / diagrams. Different from bare white CapCut type (`capcut-center-captions`) — the box is the brand of this format.

## Look
- White sans, medium weight, sentence case / lowercase chunks.
- Solid **black rectangle** behind text (sharp or lightly rounded corners).
- Centered; often sits on the split line between diagram and face.
- 2–6 words per beat.

Closest fonts: **Inter Medium**, **Helvetica Neue Medium**, **Montserrat Medium**.

## Motion
- Instant appear / hard cut with VO.
- Box width auto-fits text (or fixed max width with wrapping rare).
- Clear on pauses; no bounce.

## DaVinci Resolve Studio
1. Text+: white fill; enable **Background** (black, opacity 100%, padding ~12–20px).
2. Corner radius 0–8 px.
3. Center align; Tracking slightly tight.
4. Cut clips to VO phrases; duplicate style into Power Bin `Rumil/Black Box Captions`.
