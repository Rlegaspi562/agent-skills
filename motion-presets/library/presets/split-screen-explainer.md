# Preset: Split-screen tech explainer

**id:** `split-screen-explainer`

## When to use
Rumil shorts that teach a system, outage, or workflow — face builds trust on the bottom; diagrams do the "show" on top. Steal when the point needs a chart/architecture, not just kinetic captions.

## Look
- Hard **horizontal split** (~45–50% top / 50–55% bottom).
- Top: flat off-white / beige board, black strokes, one accent color.
- Bottom: talking-head (mic-in-hand OK), kitchen/office natural light.
- Midline: black-box captions (see `black-box-captions`).

## Motion
- Hard cuts between top-panel states timed to VO beats.
- Optional: chart line draw-on; icon scale-in.
- No flashy wipes — clarity over spice.

## DaVinci Resolve Studio
1. Edit: stack talking-head on V1; Crop/Transform to bottom half (or Fusion Crop).
2. Place diagram stills / Fusion comps on V2 in the top half (Transform position/scale).
3. Optional Adjustment clip with a thin divider line.
4. Captions on V3 using `black-box-captions`.
5. Save as timeline preset / Power Bin `Rumil/Split Screen Explainer`.
