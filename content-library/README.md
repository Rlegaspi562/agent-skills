## How to add

1. Create `sources/YYYY-MM-DD-slug.md` from a dropped URL.
2. Capture: source, one-line why it matters, adopt status (`shelved` | `testing` | `active`), key steps/prompts, Fabinal angle.
3. Link the new card from the index table below (newest first).
4. Do **not** auto-build or film from a shelved card unless Rumil asks.
